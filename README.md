# SURAPID Elevator Kazakhstan

Официальный сайт-визитка дистрибьютора лифтов SURAPID (New Xi'ao Elevator Group) в Казахстане. Одностраничный сайт на чистом HTML/CSS/JS с переключением языков RU/KZ.

## Возможности

- Каталог продукции (пассажирские, панорамные, коттеджные, больничные, грузовые лифты, эскалаторы, траволаторы, компоненты) с модальными карточками и техническими характеристиками
- Бесконечные draggable-карусели: фотогалерея и отзывы
- Мобильное меню (гамбургер ↔ крестик), переключатель RU/KZ, фиксированная шапка
- Форма заявки (RFQ) — фронтенд-версия, без бэкенда
- Плавающие кнопки: WhatsApp и локальный AI-помощник (отвечает на вопросы о продукции/услугах на основе базы знаний сайта, без внешнего API)

## Запуск локально

```bash
node serve.mjs
```

Сайт откроется на `http://localhost:3000`.

## Скриншоты

```bash
node screenshot.mjs http://localhost:3000 [label] [width] [height] [fullPage]
```

Скриншоты сохраняются в `temporary screenshots/` (не отслеживается в git).

## Структура

- `index.html` — разметка и стили (Tailwind CDN + кастомные токены)
- `data.js` — переводы (RU/KZ), каталог продукции, галерея, отзывы, база знаний AI-помощника
- `app.js` — логика: i18n, меню, карусели, модальные окна, форма, чат-виджет
- `Photo/` — фотографии производства, шоурума и продукции SURAPID
